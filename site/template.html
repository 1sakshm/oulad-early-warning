A model learns from one year of students and is tested on the next year's, people it has never seen. It is supposed to flag the students who will fail or drop out. It misses older students more often, and a better threshold doesn't fix that.

Results

The random split overstates accuracy, but only a little

Every model loses about 0.01 to 0.02 AUROC when tested on next year's students. The drop is real (its 95% interval stays above zero for every model) but small. The bigger story is how weak early prediction is: no model reaches 0.75.

Method

Two ways to test the same model

Six Open University modules ran in both 2013 and 2014. The difference between the two tests is who ends up in the test set. The questions, splits, models and metrics were committed to Git before the data was downloaded; every later change is in the deviation log.

Limits

What this does not show

One institution, one year apart

The Open University in 2013 and 2014, the same modules. A different university or a longer gap could drop much more.

Clicks are not causes

Older at-risk students click more early on. That describes the data; it does not say why they fail or leave.

Post hoc pieces are labelled

The trained threshold, the click curves, feature importance and per-module accuracy were added after the planned results.

Biased gap intervals

A gap is the largest minus the smallest group, so noise always inflates it, most of all for six deprivation levels.

Withdrawal counts as at risk

Some students withdraw for reasons a click log cannot show: work, illness, family.

Data from a mirror

The Open University link now returns 404; the data came from the UCI repository copy, checksummed.

Reproduce

Run it yourself

  1. Clone the repository and install the pinned requirements (PyTorch from the CPU index).
  2. Download OULAD, put the seven CSV files in data/raw/, and check them against data/SHA256SUMS.txt.
  3. Run these from src/. The full run takes about 15 minutes on a laptop CPU.
python -m oulad.features    # feature tables for days 14 and 28
python -m oulad.run         # all models, splits and bootstrap intervals
python -m oulad.report      # results/RESULTS.md and figures
python -m oulad.threshold   # post hoc threshold analysis
python -m oulad.describe    # descriptive numbers for this website
